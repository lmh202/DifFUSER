# Radar–Camera BEV Fusion

A research project on low-cost BEV perception for autonomous driving using millimeter-wave radar and cameras.

## Overview

The project explores radar–camera fusion as a practical alternative to LiDAR-heavy perception stacks, with an emphasis on robustness under changing weather conditions.

Main components include:

- radar + camera BEV feature fusion;
- weather-aware adaptation of fusion behavior;
- controlled evaluation under different environmental conditions.

## Status

This repository currently serves as a public project summary. The full research implementation and experimental assets are not publicly released here.

## Research context

This work was completed as part of my undergraduate research in autonomous-driving perception at Shanghai Jiao Tong University.
